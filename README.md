# 3D打印手办分件skill

**中文说明** · [English guide](README.en.md)

把 AI 生成或扫描得到的手办白模拆成能分别打印、喷涂和装配的零件。这个 Codex 技能处理的是整套制作决策：一束刘海挡住右眼，脸件该往哪里取出？小臂和包已经熔在一起，修哪一面才能留下原来的手势？它先读真实网格，再带你逐项定方案。

## 安装与调用

```sh
git clone https://github.com/Iron237/3D-Print-Figurine-Splitting-Skill.git
```

也可直接下载[最新技能 ZIP](https://github.com/Iron237/3D-Print-Figurine-Splitting-Skill/releases/latest/download/figurine-print-kit.zip)，解压得到同名技能文件夹。使用 Git 安装时，将仓库里的 `skills/figurine-print-kit` 整个文件夹复制到 Codex 的技能目录。默认位置是 `~/.codex/skills/`，设置了 `CODEX_HOME` 时使用该目录下的 `skills/`。安装后可在新对话里明确调用：

> 用 $figurine-print-kit 检查这个扫描白模。我只有 PLA 和 0.2、0.4 mm 喷嘴。请先 grill 我，一次确认一项分件与喷涂选择，待我确认方案后再切。参考图只用于配色，优先保留原发型和手势。

附上原模型，说明已有的设备、材料、比例或限制。只有配色图也可以先给；成品尺寸没定时，可以委托 AI 测量细部后推荐。如果只想讨论，直接写“只出分件方案”。

## 怎样确认分件

| 阶段 | 技能具体做什么 |
|---|---|
| 查看原模 | 保留源文件和装配坐标，核对单位、实例变换与壳体，渲染正侧背面和遮挡处截面。扫描噪点、贴图色线、真实衣边分别核实。 |
| 一次问一个问题 | 从最影响成品的选择开始，每次给基于当前模型的推荐。例如“是否要把整张脸拿在手上画眼睛？”已能测出的信息直接使用。 |
| 确认分件表 | 每件记下喷涂部位、拆开或连体遮盖的理由、藏缝位置、装入方向和固定方式。参考图如果超出原模型，以用户确认的改造范围为准。 |
| 实际切件 | 沿发际、袖口、腰口、袜口等自然分界切开，重建缺失的隐藏面。拆开看每件，再装回原位看整尊。 |
| 验证及交付 | 回读最终 STL，检查装配状态和拆卸中途，按工艺试切片。交付编号分件、装配参考、喷涂表和正反装配顺序；需要时另附试配块。 |

**还原度优先时**，先修看不见的穿模面，再试微移或改变装配顺序。如果强行分离会毁掉眼睑、手指、发梢或薄布轮廓，就保留合理连体，再用遮盖解决分色。用户撤回的配件同步从网格、预览、清单和交付包移除。

## 装配规范

- **从动作反推切口。** 静止时能贴合的零件，拔出一半可能卡在发束里。先画出抽出方向和挡路件，再决定单件直插、分段移动或成组安装。取下动作的终点还要确认榫尖已越过孔口、倒扣完全脱开。
- **每个接口有尺寸依据。** 明确公母件、榫形、插入轴、有效深度、单边间隙、孔底余量及最薄孔壁。单脚站姿还应看从鞋底到髋部的受力路径。双榫要有可共同进入的一段行程。
- **分别决定干插和点胶。** 可换脸或补妆的头部优先保留可拆；承重鞋底可在试配后点胶。涂装前遮住榫、孔和定位肩面。FDM 考虑层纹受力和拆支撑，树脂件另看收缩、支撑接点及空心腔的排液。
- **把验证说具体。** 网格闭合、数码试装、生成切片、实机打样各有不同的证据。FDM 核对实际挤出路径，光固化核对树脂配置与有效曝光层。记录到底做了哪一步，返修后复核受影响的最终文件。

完整的[逐问策略](skills/figurine-print-kit/references/grill.md)和[分件与装配规范](skills/figurine-print-kit/references/assembly.md)随技能安装。

## 可选几何工具

以下命令在仓库根目录执行。技能访谈和规范本身无需 Python。脚本读入模型、输出 JSON，不会修改输入。

```sh
python -m pip install -r requirements.txt
python examples/joint_demo.py
python -X utf8 skills/figurine-print-kit/scripts/inspect_mesh.py model.stl
python -X utf8 skills/figurine-print-kit/scripts/check_fit.py assembly-check.json
```

- **inspect_mesh.py** 报告场景边界、实例、三角面、边界边、非流形边等；STL 的物理单位没有依据时保留未知。点云可初检，仍需重建才能作为切件实体。
- **check_fit.py** 读取同一装配坐标中的毫米 STL，检测静态体积相交，并沿用户指定的分段平移路径采样。清单应列明移动件、留在原位的件和累计位移。各自贴床居中的打印 STL 需先恢复到装配坐标。退出码 0 表示所检范围在阈值内，1 为检出相交，2 为输入或运算失败。零件能否旋出、弹性变形或承重需另行验证。[清单格式与结果判读](skills/figurine-print-kit/references/verification.md)
- **joint_demo.py** 生成一对带平面的定位榫和母座，用同一套几何演示沿轴拔出和横向拔出的区别。演示使用临时目录。

最小清单如下。位移是相对装配姿态的累计平移。每步写明一起移动的件和仍会挡路的件，省略 paths 即只检查静态。细发束附近宜缩小步长或检查连续扫掠体。

```json
{
  "units": "mm",
  "tolerance_mm3": 0.005,
  "step_mm": 0.25,
  "parts": {"peg": "peg.stl", "socket": "socket.stl"},
  "paths": [
    {"name": "axial withdrawal", "moving": ["peg"], "fixed": ["socket"],
     "offsets_mm": [[0, 0, 0], [0, 0, 12]]}
  ]
}
```

## 一个实际案例

一尊单脚站立的 PLA 手办最终做成 250 mm 高、15 个正式件。前脸独立画眼，原翘发留在前发，挎包的细肩带贴衣保留。头部先在手中组合脸与前发，再落到颈座，最后把后发的长定位榫从背后送进脸件。该例采用 0.20–0.25 mm 单边间隙，另外做了一对试配块。15 个正式件均通过数字回读和切片检查，未进行实机试打。

这些数字展示的是一次具体取舍。另一尊树脂胸像或另一种比例，应从它的脸、支点、薄件截面和打印条件重新定尺寸。公开案例只记录决策和验证范围。[阅读案例复盘](skills/figurine-print-kit/references/worked-example.md)
