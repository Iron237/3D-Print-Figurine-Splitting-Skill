# 可拆脸的导入口与多盘打印工程

[English](face-and-plates.en.md)

## 脸背与颈座的修顺

先在装配坐标中找出穿过前发的长榫、脸背孔和颈座孔。分别沿各自的插入轴剖开，确认最先接触的是发际缝边、孔口还是孔底。保留初版脸件、孔口中心、插入轴、榫尖与孔底位置作为对照。

1. 用正面、斜侧和俯仰视图标出要保留的眼睑、鼻尖、唇线、脸颊及下颌轮廓。锁住原雕刻、孔内直段和孔底，只在脸背人工切面和窄过渡带内重布网格、修顺折面。两侧太阳穴较薄，要从外面复看。
2. 若直榫能进孔但起插刮边，在孔口按原键形做圆滑扩口。沿插入轴用数个同形截面放样，平滑接入原有直孔。D 形平边随截面保留。分别量剩余直段、孔底余量和到外表皮的壁厚。按每个孔周边的实体和插入方向定扩口长度。
3. 在入口与直段的交界、接近榫尖处做径向截面，并沿轴测孔底。把前脸与前发先组合，在颈座上复位，再验证后发长榫穿越前发并进入脸背的路径。对比同机位的眼鼻口表面与两侧外轮廓。回读装配姿态和打印姿态的最终网格，检查闭合和自交。如需实机确认，从最终接口[截取公母小样](seams-and-coupons.md)。

## 按实际耗材、喷嘴和工时排盘

先确认机型、可打印区域、热床类型、实际要上的线材及可用喷嘴。给每个正式件记录编号、打印摆位、线材、喷嘴、层高、估时及哪些面怕支撑痕。喷涂成品的肤色、发色和衣色可以共用一卷白 PLA。用户确实要上线不同线材时，再按实物线材及兼容设置分组。

- 同喷嘴、同工艺优先同盘。保留脸件和薄发的方向，再绕床面法线旋转或平移以缩短空程。树支撑、裙边、热床禁区和高而窄的零件都要参与排布判断。逐件打印要额外校核打印头扫掠空间。
- 用单件估时做初排，再以整盘切片结果平衡长任务。盘数、总开机次数、换嘴次数和单盘失败的重打成本都影响效率。保留分盘依据及每盘实测的切片估时和用料。
- 在 Bambu Studio 建立可编辑的多盘工程。每个正式件作为独立可选的打印实例分配到对应盘，每盘命名写明盘号、线材和喷嘴。可选试打件单独标识。手动摆盘或使用原生 assemble-list 导入分盘及位置。已有装配母版时，保存打印摆位到装配坐标的逆变换，用同一套几何恢复装配视图。
- 单喷嘴机型的可编辑工程有一个当前喷嘴预设。将默认值设为第一批要用的喷嘴。在换嘴盘名及随件说明中写明需更换实体喷嘴、切换机器和工艺预设，再切当前盘。把必要的支撑、壁数等设置保存在对象或相应工艺中，复查切换预设后仍生效。

## 用最终工程逐盘验收

1. 重新打开交付的 3MF，核实机型、热床、线材、每盘编号及唯一实例数，检查有无漏件、重复、悬空、越界或相碰。若有装配视图，单独验证恢复后的相对位置和总高。
2. 每次只切目标盘，使用该盘对应的机型、喷嘴、工艺和耗材预设。核对结果中的机型、喷嘴直径、层高、盘号与对象标识。查看各件本体的实际挤出路径，确认支撑、首层和裙边的覆盖范围，处理切片器警告。
3. 交付一份可编辑的 3MF 和逐盘清单，注明默认配置、换嘴时机、用料、工时以及是否实打。修改脸件、摆位、支撑或配置后，从最终文件重新切受影响的盘。

[inspect_plates.py](../scripts/inspect_plates.py) 读取 Bambu Studio 原生盘表、实例、项目预设和已有切片头。可分别对可编辑母版和逐盘切片文件运行。没有内嵌 G-code 的母版可正常用于后续编辑、切片。脚本给出的对象标签和估时用于核对，还需检查实际刀路。

```sh
python -X utf8 scripts/inspect_plates.py project.3mf
```

本例使用 P2S、256 × 256 mm 热床和一卷白色 PLA。7 个细节件分到两盘，用 0.2 mm 喷嘴；其余 8 件合为一盘，用 0.4 mm 喷嘴。三盘共换嘴一次。其他机器、模型尺寸和线材组合应按自身条件重新排布。[Bambu Studio 命令行及按盘切片示例](https://github.com/bambulab/BambuStudio/wiki/Command-Line-Usage)
