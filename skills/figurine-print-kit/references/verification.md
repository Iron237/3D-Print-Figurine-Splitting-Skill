# 只读验证工具

脚本相对于本技能目录运行；遇到缺少几何库时可改用现有建模环境做等效检查。Python 脚本用 NumPy、SciPy、trimesh，实体求交另用 manifold3d。3MF 等格式可能需要对应的加载器依赖（如 lxml）。两者将 JSON 写到标准输出，均不改动模型。

## 检查输入

```bash
python -X utf8 scripts/inspect_mesh.py source.stl
python -X utf8 scripts/inspect_mesh.py assembled.3mf
```

各几何体单独检查拓扑，包围盒计算包含所有实例的世界变换。STL 一般没有单位；在得到实物尺寸依据后，可用 `--mm-per-unit 1` 等明确换算。对无面点云只报告点和尺寸。点接触也可能归为同一个顶点连通体。闭合、面朝向一致仍可能有自交、内部壳或融合的不同部位，需要结合视图和截面核实。

## 检查接口与路径

将建模母版中的每个正式件按**相同装配原点、相同轴向、毫米单位**另存 STL。已经各自贴床居中的打印 STL 需要先恢复装配变换。静态求交包括所有已登记的件；每条运动只计算该步骤中拿在手上的件与明确留在原位的件。嵌套子组件可用多个 moving 编号。

在装配 STL 同目录写一份清单。下面数字仅演示输入格式，实际项目按其尺寸、误差预算和抽出路径填写。

```json
{
  "units": "mm",
  "tolerance_mm3": 0.005,
  "step_mm": 0.25,
  "parts": {"face": "face.stl", "fringe": "fringe.stl", "rear": "rear.stl"},
  "paths": [
    {"name": "withdraw rear", "moving": ["rear"], "fixed": ["face", "fringe"],
     "offsets_mm": [[0, 0, 0], [0, 6, 1], [0, 22, 4]]},
    {"name": "release face on bench", "moving": ["face"], "fixed": ["fringe"],
     "step_mm": 0.12, "offsets_mm": [[0, 0, 0], [1, -2, -3], [3, -20, -4]]}
  ]
}
```

```bash
python -X utf8 scripts/check_fit.py assembly-check.json
```

坐标是相对于装好位置的**累计平移**。相邻路径点会插值并包含端点。只需静态检查时省略 paths，输出会标记 motion_checked 为 false。退出码 0 表示所检范围内无超过阈值的相交，1 表示检出相交，2 表示输入或计算失败。报告给出零件对、最大采样相交体积与当时的位移。零体积接触、最小壁厚、机械承重、旋转抽出和采样点之间的碰撞都需要另外判断。细发梢等易漏部位应缩小步长或改用连续扫掠检查。对标为“取下”的路径，用截面或沿轴投影核对终点：榫尖已越过孔口、倒扣已经脱开，零件也有空间继续移走。只移动一小段可能全程无碰撞，却仍插在孔里。

## 交付前对照

- 回读打印 STL 的物理尺寸和拓扑。通常一个文件对应一个可拿起的零件；设计本就有空腔、多个壳或多材质时，按实际设计解释。
- 以装配坐标核对装配文件的零件数、变换、外包尺寸，以及脸、手、发梢等局部。给打印方向明确标记，避免读者把装配参考整件送印。
- 在实际切片器中载入已摆好的正式 STL。FDM 核对机器、材料、喷嘴和挤出路径；光固化核对机器、树脂配置和有效曝光层。记录配置和失败项。若只检查过模型或切片预览，就如实标出，避免写成已实打。
- 返修后至少重新验证受影响的部件与邻接件，再次导出对应的 STL、装配图和压缩包，使验证记录对应最终文件。
