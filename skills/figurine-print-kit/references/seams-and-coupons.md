# 修顺接缝、设计定位面与截取真实接口试打

[English](seams-and-coupons.en.md)

## 找到真正卡住的面

在装配母版上记下接缝、插入轴和目标尺寸。拆开相邻件，用同一机位和斜光看外露缝线、切开的内壁、榫根和孔口，再沿插入轴剖开。拿原模对照，辨认应保留的衣边、发梢或睫毛。预览里出现锯齿时，检查最终 STL 的截线及切片层轮廓，区分网格毛刺、显示阴影和支撑接触痕。

- 内壁出现**台阶、薄刺或不规则三角面**时，标记人工切面并沿网格连通关系选一圈窄过渡区。锁定相邻雕刻、榫直段和孔壁，局部重布网格、松弛，再移除翻折的小片。把过渡强度向外减到零。用独立零件复看，尤其是薄发壳的另一面。
- 发现**外露缝线参差**时，在共同装配坐标中，沿衣褶、发际或色界画一条双方共用的平顺边界。用它重新裁切两面，向内侧退让。每次只试一小段，合回去看有无亮缝、错台或丢失的轮廓。单独把两条边各磨圆，常会把可见缝隙越磨越宽。
- 遇到**榫能进孔却推不到底**的情况，先看轴向截面，找最先接触的两处。榫尖顶底时增加孔底余量，榫肩撞毛边时修承接面，多榫互相拉扯时核对共同插入方向和辅助孔侧隙。切片预览能定位堵孔的支撑或缺失的薄壁。实打才出现的紧配，还需查首层外扩、流量和漆膜。

## 用榫导向，用肩面控制插入深度

在看不见且两侧都有实体的位置布榫。D 形平边可防转，母孔沿整个截面等距外偏，平边也要留出单边间隙。在入口处开短倒角，引入后仍留足直段。依次量榫根有效截面、最薄孔壁、直段啮合和孔底轴向余量。多榫同时进入时，选一个主定位孔，只在可能积累误差的辅助孔方向放宽，并复查抗转能力。

腰口、裙内或袜口有足够材料时，可围绕已有榫做环形止口。沿插入轴在公件留平肩，在母件开同轴沉孔和环形承接面。分别设定榫与孔的单边间隙、肩外圈与沉孔的侧隙以及轴向余量。沿整圈剖查背后的实体厚度，特别留意倾斜的接缝。薄发壳、细袖口若容不下环肩，保留短导入口、防转榫或浅定位点胶。单脚承重还要检查从底座到髋部的完整受力路径。

在同一装配姿态、相同半径和方位角上采样。沿插入轴量环面的最大与最小高度之差，同时看公母面的间距和最先接触处。记录采样数、单位和有意保留的避让缺口。高差包含切面原有的坡度，是检查止口平整度的模型数据。另用同机位近景比接缝，用多方向轮廓比角色外观。修完后用最终导出的实体重查自交、合拢及中途插拔。

## 直接从成品件取试打件

1. 选最影响装配的一对，例如主要承重的袜口，或最难对正的发榫。取同一最终版本公母件，恢复到共同装配坐标，以毫米按 100% 比例截取。用**同一个裁剪体分别与两件求交**，保留整个榫尖、榫根、导入口、直孔、孔底、肩面及周边壁厚。抓持端或平底可放在远离配合面的位置。
2. 用截面叠回正式件，确认孔底没有被截穿，榫尖和环肩完整，多条细发也没有误入。单榫小样只回答该处松紧；要判断双榫中心距或能否同步进入，截取包含两榫和两孔的整组。头部组合的装入次序仍用完整子组件验证。
3. 逐件套用正式件的打印朝向，以及同材料、喷嘴、线宽、层高、流量、补偿和支撑接触条件。改成平底易打时，注明改动以及对层纹、支撑或孔径的影响。回读并单独切片，确认支撑可清除、孔壁有路径；耗材和时间单独统计。
4. 裸件先去除支撑和孔口凸丝，沿键平面对齐直推。记录从哪里开始紧、肩面能否就位、有没有晃动以及能否沿轴拔出。若要验证漆后手感，复现正式件的遮盖、底漆和涂层。将修正回写正式接口，重新截样并复查邻接件。分别记录数字检查、切片和实打的结果。

### 用脚本截取

[extract_fit_coupons.py](../scripts/extract_fit_coupons.py) 使用同轴圆柱裁剪。下面假设孔口在原点、插入方向为 +Z，长度均为毫米。从技能目录运行，把文件和尺寸换成目标接口的实测值。

```sh
python -X utf8 scripts/extract_fit_coupons.py peg.stl socket.stl samples/waist --center 0 0 0 --axis 0 0 1 --radius 8 --behind 4 --ahead 10
```

`--behind` 从孔口朝榫根，`--ahead` 从孔口进母孔。半径须覆盖完整止口并留住邻近壁厚。输出到新目录的 `male.stl` 和 `female.stl` 保留装配坐标，便于叠回检查，然后分别施加正式件的打印摆位。圆柱裁到多块分离实体时，调整范围，或在 CAD 中沿实际部位轮廓截取。尺寸间隙和裁剪范围均由当前模型决定。
