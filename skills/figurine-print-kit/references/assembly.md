# 分件与装配规范

## 从喷涂边界找真实切面

1. 在共同装配坐标中看正、侧、背、斜下方和局部截面。扫描贴图上的色线、网格锐边、真实零件交界可能落在三个不同位置。先找到接缝能被发束、翻领、鞋口或内衬遮住的位置。
2. 分别记录每件的可见面、邻接件和装入方向。实体相交时判断哪些体积属于可见雕刻，哪些是融合后才有的内壁。单张正视图很容易把脸侧分到头发，也容易把贴包小臂的一段分给包。
3. 一体网格可用多视图表面标注，借锐边或曲率扩展到完整区域；截面确认归属后再构造切割体。把体素或距离场用于求复杂的**内部分界**，与原高精网格做局部相交。切面需封口，两侧要有足够实体安置榫根和孔壁。
4. 试切后隐藏相邻件，单独转看每件。检查完整眼睑、下巴、手指、发尾、裙内侧以及本该留在别件上的皮料碎片。空心壳的内壁与外壁也可能属于同一件。发现孤岛时先定位再决定归还、桥接、独立或舍弃。高模简化和修洞应复看脸部斜光，防止轮廓近似但脸颊已经显出大三角面。

## 处理穿模与薄件

由轻到重试选局部修复方式，先在装配视图验证效果。可接受的修改由当前项目决定。

| 情形 | 处理 |
|---|---|
| 两实体只在背面相穿 | 判断谁保留原表面，在接收件内部做止口和避让，保留邻件厚度。 |
| 悬空指尖、耳饰或发束过细 | 量根部有效截面和悬空长度。可加内侧圆滑过渡、并到稳定主体或调整摆放，让支撑能从厚处卸下。 |
| 拆开会露出缺失的手臂、脸侧或衣褶 | 根据原有截面和多视图延续轮廓；所需补塑明显超出可见依据时，先尝试微移或连体遮盖。 |
| 平移时发束夹住脸，手臂挡住后发 | 先尝试改变次序、成组装入、分段退出；再酌量修改暗面。两者都需要大幅损伤可见轮廓时，把相关小部位并件。 |
| 穿模位置本来就是衣面肩带、发卡或包上小挂件 | 对照独打厚度、粘接面积和遮盖难度，保留可上色的浮雕通常更稳。 |

改位移前同时核对角色姿态和相邻接口。保留鼻尖、眼睑、手指或衣褶的一侧，另一侧承担局部让位。若改变了可见设计，在最终清单中标明。

## 设计接口

- **定位与承重分开考虑。** 从重量、重心和支点推断力矩，沿脚底、脚踝、髋部和底座传递载荷。D 形、双扁、偏置双榫适合防转；空间充分时，用有间距的两榫或止口承受侧向力。空心母件可局部增厚。细装饰可用浅定位加点胶。金属轴、磁铁或螺钉涉及新材料，依用户已有条件选择。
- **有统一的配合定义。** 记录公件、母件、插入轴、榫径或轮廓、有效插入深度、单边间隙和孔底余量。圆榫的母孔直径等于公榫直径加两倍单边间隙；D 形截面可将完整轮廓等距外偏。加导入倒角并核对最薄孔壁。孔底预留量独立计算。多榫同时插入时，各轴要能共享同一段实际运动。
- **工艺决定间隙。** 使用用户的喷嘴、实际线宽、层高、PLA 状态或树脂收缩记录。细榫还要考虑打印方向和清支撑载荷。无实测时，给出清楚标注的设计起点，用同方向、同截面和同材料的小样确认。若改整体比例，在目标尺寸上重新生成接口并复算间隙。
- **按件选择固定方式。** 眼妆返修、换脸或更换配件偏向可拆。承重部位先做机械定位，是否最终点胶按实打手感与展示需求决定。遮住接触面，避免漆膜吃掉装配余量。

已有分件的边缘粗糙、肩面接不实或多榫难以同时插入时，按[修顺接缝与定位面](seams-and-coupons.md)区分卡点、选择修法并从最终零件截取试打件。

## 从整件合拢到真正能装

1. 先按遮挡关系列拆卸顺序，同时标出留在原地的件和随手一起移动的子组件。将这条顺序反转得到装配说明。需要二段运动时，画出释放倒扣和最终抽出的方向。
2. 对装配姿态逐对求交，再沿路径检查中途碰撞。把新增榫、孔、周边细发和临时拿在手上的组合都纳入计算。优先试最窄间隙、起始行程和转向处。终点若要完全取下零件，核对榫尖已越过孔口且所有倒扣已脱开。明显干涉先改顺序，小干涉修暗面，每次修改后复检。曲线或旋转运动应用适合的变换采样或扫掠体检查。
3. 完成前回读已导出的各件、装配文件和切片。核对原比例、部位数量、正反面、薄片孤岛和孔口。FDM 看支撑能否卸下、栽在首层上的细榫、脸和眼部的支撑痕；树脂件结合具体工艺检查支撑接点、空腔和排液连通。核实切片确实有对象挤出路径或有效曝光层。
4. 对比装回后的原模轮廓和重点局部。轮廓重合可以支撑外形判断；眼睑、表面起伏和接缝质量要靠局部视图检查。电子验证说明其采样范围，受力、摩擦和漆后手感要看实机样件。
